# LeadTrace 产品说明

## 定位

LeadTrace 合并了两套能力：

- **EchoTrace**：本地微信解密、聊天浏览、分析与导出  
- **微信 AI 助手（fantastic-funicular）**：群聊商机分段识别与结构化抓取  

产品重心是 **商务商机抓取**；聊天浏览与分析是支撑能力。

## 使用门槛

解密（或实时 WCDB 连接）是整条链路的基础：

```
配置密钥/路径 → 数据管理解密或实时连接 → 商机抓取 / 聊天 / 分析
```

未连接数据库时，「商机中心」「群监控」「聊天记录」会显示引导并跳转数据管理。

## 主导航

1. 商机中心  
2. 群监控  
3. 聊天记录  
4. 数据分析 / 群聊分析 / 导出  
5. 数据管理  
6. 设置（含 AI 配置）

## 商机类别

| 内部值 | 含义 |
|--------|------|
| recruitment | 招聘 |
| procurement | 求购 / 采购 |
