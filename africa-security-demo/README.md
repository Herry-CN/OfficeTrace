# 非洲安防空地一体综合管理平台 Demo

基于《非洲安防系统需求假设》与「天地一体综合管理平台」录屏交互形态搭建的前端演示。

## 定位

不是机器狗销售页，而是面向高风险客户的 **设备 + AI + 通信 + 人员 + 情报** 安全能力指挥舱。

## 场景

- **工程营地**：肯尼亚高风险中资项目营地巡逻、油料区防护、入侵空地联动
- **高端别墅**：夜间静音巡航、「黄金5分钟」入户窗口期预警

## 多语言

右上角支持 **中文 / EN** 切换，界面文案与场景内容同步切换，语言偏好会写入 `localStorage`。

## 手机端

左上角可切换 **指挥舱 / 手机端**，或访问 `?view=mobile`。

手机端包含：首页、告警、**实时画面与对讲**、设备。

实时页支持：
- 切换无人机 / 机器狗画面源
- 光学 / 热成像 / 分屏
- 按住说话对讲、声光驱离与截图动作（演示模拟）

## 模块

- 地图 / 飞行成果：卫星底图、航线航点、无人机/机器狗/感知设备
- 预警线索：待处理 / 处理中 / 已处理
- 设备资产：无人机、机器狗、机巢、相机、Starlink 中继
- 空地联动：摄像头 → AI → 无人机 → 机器狗 → 指挥中心
- 五层架构：设备层 → 感知层 → AI层 → 运营层 → 解决方案层

## 运行

```bash
cd africa-security-demo
npm install
npm run dev
```

## 测试

```bash

npm run build
```
